# Credits

animate-pls is built on other people's open-source work.

- **[animate](https://github.com/cth9191/animate)** by cth9191 (MIT) is the base: the styles, kit, story grammar and tools. animate-pls adds the free voice, the one-take format, install for any agent, and fixes for square and wide pieces. The [licence](../LICENSE) keeps cth9191's copyright notice alongside samadpls'.
- **[onetake](https://github.com/feitangyuan/onetake)** by feitangyuan inspired the one-take format. Only the idea is used; no code or text from it is here.
- **[VoxCPM2](https://github.com/OpenBMB/VoxCPM)** by OpenBMB (Apache-2.0) is the voice.
- **[faster-whisper](https://github.com/SYSTRAN/faster-whisper)** (MIT) times the words.

More video skills for coding agents: **[awesome-claude-video-skills](https://github.com/zhuyansen/awesome-claude-video-skills)**.
