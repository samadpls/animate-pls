# Resources

The best open projects and guides found while building this release, with their licences. Use them to go further, or to pick a different tool when animate-pls is not the right fit.

## Video skills for coding agents

| Project | Licence | Why it is worth a look |
|---|---|---|
| [HyperFrames](https://github.com/heygen-com/hyperframes) | Apache-2.0 | HTML to MP4 for agents, with about 450 ready blocks (captions, charts, transitions). Heavier than animate-pls (GSAP, Node 22). |
| [video-use](https://github.com/browser-use/video-use) | MIT | Edits raw footage through a transcript and an edit list. The clearest rules for cutting talking-head video. |
| [explainroo](https://github.com/vincentsch/explainroo) | MIT | A close relative: canvas explainers with a local voice and word-lit captions. |
| [lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar) | MIT | 59 film styles, each with a detailed style spec. |
| [anidoodle](https://github.com/alexgreensh/anidoodle) | Apache-2.0 | 32 hand-drawn styles that can film themselves being drawn. |
| [drawn-by-code](https://github.com/illodev/drawn-by-code) | MIT | Canvas animation drawn by an agent, with clay, comic and poster kits. |
| [motion-canvas](https://github.com/motion-canvas/motion-canvas) | MIT | A code-first animation engine; its code-diff animation is excellent. |
| [awesome-claude-video-skills](https://github.com/zhuyansen/awesome-claude-video-skills) | list | Over 350 video skills for coding agents, kept up to date. |

## Editing screen recordings

| Project | Licence | Why it is worth a look |
|---|---|---|
| [OpenScreen](https://github.com/siddharthvaddem/openscreen) | MIT | A free Screen Studio alternative: zooms, cursor smoothing, padded frames. |
| [Screenize](https://github.com/syi0808/screenize) | Apache-2.0 | Plans camera moves from what the user is doing (typing, clicking, reading). |
| [screenstudio-alt](https://github.com/connerkward/screenstudio-alt-skill) | MIT | A Screen Studio style polish pass packaged as an agent skill. |
| [auto-editor](https://github.com/WyattBlue/auto-editor) | Unlicense | Cuts dead air by loudness and motion. |

## Reels and captions

| Resource | Why it is worth a look |
|---|---|
| [TikTok In-Feed ad specs](https://ads.tiktok.com/help/article/tiktok-auction-in-feed-ads), [Instagram Reels guide](https://www.facebook.com/business/ads-guide/update/video/instagram-reels), [YouTube vertical safe zones](https://support.google.com/google-ads/answer/9128498) | The official areas the app buttons cover. animate-pls keeps captions inside all three. |
| [pycaps](https://github.com/francozanardi/pycaps) (MIT) | Animated caption templates with clear numbers for size and chunking. |
| [LinkedIn video specs](https://www.linkedin.com/help/lms/answer/a424737) | Length, ratio and caption advice for LinkedIn. |

## Packaging one skill for many agents

| Resource | Why it is worth a look |
|---|---|
| [Agent Plugins 1.0](https://github.com/agentplugins/agent-plugins-spec) | One `plugin.json` read by Codex, Cursor, Copilot and VS Code. |
| [Codex plugins](https://developers.openai.com/plugins/build/plugins) | How Codex installs plugins from a marketplace. |
| [Cursor plugins](https://cursor.com/docs/reference/plugins) | Cursor's plugin and marketplace files. |
| [OpenCode skills](https://opencode.ai/docs/skills/) | Where OpenCode looks for skills. |
| [skills CLI](https://github.com/vercel-labs/skills) (MIT) | `npx skills add` installs a skill into most agents. |
